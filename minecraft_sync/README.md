# Minecraft World Sync

Приложение для синхронизации игрового мира Minecraft Java Edition между участниками виртуальной локальной сети Radmin VPN.

## 🚀 Быстрый старт

### 1. Установка и запуск

```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
python src/main.py
```

Или используйте готовый `.exe` файл (после сборки через `build.bat`).

### 2. Настройка TLauncher (если не найден автоматически)

Если программа выдаёт ошибку `TLauncher not found in standard locations`:

1. Найдите `TLauncher.exe` на компьютере (обычно в `%APPDATA%\.tlauncher\`)
2. Создайте файл `tlauncher_path.txt` в папке с программой
3. Запишите в него полный путь к `TLauncher.exe`
4. Перезапустите программу

**Пример содержимого `tlauncher_path.txt`:**
```
C:\Users\danil\AppData\Roaming\.tlauncher\TLauncher.exe
```

**Альтернатива:** Запустите TLauncher вручную перед нажатием кнопки "Играть".

### 3. Подключение к комнате

1. Введите пароль комнаты Radmin VPN
2. Выберите мир из списка
3. Нажмите "Играть"

Первый запустивший становится хостом, остальные подключаются автоматически.
