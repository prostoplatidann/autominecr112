# Changelog

## [1.1.0] - 2026-05-20

### Изменения
- ✅ **Автоматический запуск TLauncher через командную строку** с параметрами `-login`, `-start`, `-version`
- ✅ **Увеличен размер окна приложения** (550x480) для корректного отображения кнопки Settings
- ✅ **Добавлена возможность изменения размера окна** (resizable)
- ✅ **Улучшены отступы кнопок** для лучшего визуального оформления
- ✅ **Fallback на GUI автоматизацию** если запуск через командную строку не удался

### Технические улучшения
- TLauncher теперь запускается с аргументами: `TLauncher.exe -login <username> -start -version forge-1.21.1`
- Автоматический выбор версии Forge и запуск игры без вмешательства пользователя
- Сохранена резервная система эмуляции кликов через pyautogui
- Улучшено логирование процесса запуска

### Исправления
- 🐛 Кнопка Settings больше не обрезается
- 🐛 Окно программы имеет достаточный размер для всех элементов
- 🐛 TLauncher запускается сразу с нужной версией

## Версия 1.0 (2024)

### Основные возможности
- ✅ GUI с выбором мира и настройками
- ✅ Сетевое обнаружение через Radmin VPN (UDP broadcast)
- ✅ Измерение пинга между участниками (ICMP)
- ✅ Шифрование AES-128-CBC для передачи миров
- ✅ Версионирование миров
- ✅ Архивация и передача миров (ZIP_STORED)
- ✅ Автоматический запуск TLauncher
- ✅ Forge-мод для авто-LAN и подключения
- ✅ Мониторинг процесса игры
- ✅ Синхронизация при выходе хоста
- ✅ Логирование событий

### Компоненты
1. **Python-приложение** (`src/main.py`)
   - Класс `CryptoManager` - шифрование/дешифрование
   - Класс `NetworkManager` - сетевое взаимодействие
   - Класс `WorldManager` - управление мирами
   - Класс `MinecraftLauncher` - запуск игры
   - Класс `SyncApp` - основной GUI

2. **Forge-мод** (`mods/WorldSyncMod.java`)
   - Авто-загрузка мира на хосте
   - Авто-открытие LAN
   - Авто-подключение на клиенте
   - Периодические триггеры бэкапов

3. **Документация**
   - `docs/README.md` - основная инструкция
   - `docs/BUILD_MOD.md` - сборка мода

### Технические детали
- UDP порт 45678 для discovery
- TCP порт 45679 для команд
- Бродкаст каждые 5 секунд
- Ping каждые 10 секунд
- Бэкапы каждые 5 минут
- PBKDF2 с 100000 итераций для ключа

### Известные ограничения
- Требуется запуск от имени администратора для ICMP ping
- TLauncher должен быть установлен в стандартном расположении
- Мод требует Forge 1.21.1
- Windows-only приложение
