# 🔧 TLauncher Автоматизация

## Что было добавлено

Теперь программа **автоматически**:
1. Запускает TLauncher
2. Выбирает версию Forge 1.21.1 из списка
3. Нажимает кнопку "Играть"
4. Minecraft запускается с нужной версией
5. Мод автоматически загружает мир и открывает его для сети

**Вам нужно только нажать одну кнопку "Играть" в программе!**

---

## 📋 Требования

### Установите pyautogui:
```bash
pip install pyautogui
```

Или обновите все зависимости:
```bash
pip install -r requirements.txt
```

---

## ⚙️ Как это работает

1. **Запуск TLauncher**
   - Программа находит TLauncher по пути из `tlauncher_path.txt` или в стандартных расположениях
   - Запускает процесс TLauncher

2. **Ожидание загрузки UI**
   - Программа ждёт 5 секунд пока TLauncher загрузится
   - Находит окно TLauncher по заголовку

3. **Выбор версии**
   - Кликает на выпадающий список версий
   - Вводит название версии: `forge-1.21.1`
   - Нажимает Enter для выбора

4. **Запуск игры**
   - Кликает на кнопку "Играть" (Play)
   - TLauncher запускает Minecraft с выбранной версией

5. **Автоматическая загрузка мира**
   - Forge-мод обнаруживает конфигурационный файл `sync_mod_config.json`
   - На хосте: автоматически загружает мир и открывает LAN
   - На клиенте: автоматически подключается к хосту

---

## 🎯 Точные координаты кликов

Программа использует относительные координаты окна TLauncher:

| Элемент | Позиция |
|---------|---------|
| Выпадающий список версий | Центр окна, 150px от низа |
| Кнопка "Играть" | Центр окна, 80px от низа |

Если у вас нестандартный размер окна TLauncher, координаты могут отличаться.

---

## 🔧 Настройка под ваш интерфейс

Если автоматизация не работает правильно, вы можете настроить координаты в файле `src/main.py`:

```python
# Найдите эти строки в функции launch_minecraft():

# Измените позицию dropdown (выпадающего списка)
dropdown_y = y + height - 150  # Поменяйте 150 на другое значение

# Измените позицию кнопки Play
play_y = y + height - 80  # Поменяйте 80 на другое значение
```

### Как найти правильные координаты:

1. Запустите TLauncher вручную
2. Запишите текущие координаты мыши (можно использовать программу типа "Mouse Locator")
3. Измерьте расстояние от низа окна до элементов управления
4. Обновите значения в коде

## ❓ Если автоматизация не работает

### Проблема 1: pyautogui не установлен
```
WARNING: pyautogui not installed - automatic startup disabled
```
**Решение:** Установите pyautogui:
```bash
pip install pyautogui
```

### Проблема 2: Окно TLauncher не найдено
```
Could not find TLauncher window - user must start manually
```
**Решения:**
- Убедитесь, что заголовок окна содержит "TLauncher"
- Проверьте, что окно не свёрнуто
- Попробуйте запустить TLauncher вручную перед нажатием "Играть"

### Проблема 3: Клики не попадают куда нужно
**Решение:** Отрегулируйте координаты как описано выше

### Проблема 4: TLauncher на другом языке
Если у вас TLauncher на английском, названия версий могут отличаться:
- Русская версия: `forge-1.21.1`
- Английская версия: `Forge 1.21.1` или `release 1.21.1-forge-...`

**Решение:** Измените переменную `forge_version` в коде:
```python
def launch_minecraft(self, username: str = None, forge_version: str = "Forge 1.21.1"):
```

## 🚀 Полный рабочий процесс

### Для хоста:
1. Запустите `python src/main.py`
2. Введите пароль комнаты
3. Выберите мир из списка
4. Нажмите **"Играть"**
5. ✨ Программа сама:
   - Запустит TLauncher
   - Выберет Forge 1.21.1
   - Нажмёт "Играть"
   - Minecraft загрузится
   - Мир откроется автоматически
   - Сервер запустится в LAN

### Для клиента:
1. Запустите `python src/main.py`
2. Введите тот же пароль комнаты
3. Выберите тот же мир
4. Нажмите **"Играть"**
5. ✨ Программа сама:
   - Запустит TLauncher
   - Выберет Forge 1.21.1
   - Нажмёт "Играть"
   - Minecraft загрузится
   - Автоматически подключится к хосту

---

## 💡 Советы

1. **Первый запуск** может занять больше времени (TLauncher скачивает файлы)
2. **Убедитесь**, что Forge 1.21.1 уже установлен в TLauncher (запустите один раз вручную)
3. **Не двигайте мышь** во время автоматизации (может помешать кликам)
4. **Закройте другие окна** которые могут перекрыть TLauncher

## 🔄 Альтернативный режим

Если автоматизация постоянно fails, программа продолжит работу в ручном режиме:
- TLauncher запустится
- Вы сами выберете версию и нажмёте "Играть"
- После запуска Minecraft мод всё равно сработает автоматически

Это менее удобно, но всё ещё работает!
