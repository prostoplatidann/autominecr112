# Minecraft World Sync

Приложение для синхронизации игрового мира Minecraft Java Edition между участниками виртуальной локальной сети Radmin VPN.

## Требования

### Системные требования
- **ОС**: Windows 10/11
- **Python**: 3.10+
- **Minecraft Java Edition**: версия 1.21.1 с Forge
- **Лаунчер**: TLauncher
- **Radmin VPN**: установлен и подключён к комнате

### Необходимые Python-библиотеки
```bash
pip install cryptography psutil netifaces pystray pillow
```

## Установка

### 1. Настройка Radmin VPN
1. Скачайте и установите [Radmin VPN](https://www.radmin-vpn.com/)
2. Создайте комнату или подключитесь к существующей
3. Запомните пароль комнаты (он понадобится в приложении)
4. Убедитесь, что ваш IP-адрес начинается с `26.` (проверьте в настройках Radmin)

### 2. Установка Minecraft с Forge
1. Откройте TLauncher
2. В списке версий выберите `Forge 1.21.1`
3. Нажмите "Создать" или "Запустить" для установки Forge
4. Дождитесь завершения установки

### 3. Установка мода WorldSync
1. Найдите папку `.minecraft`:
   - Обычно: `C:\Users\<ИмяПользователя>\AppData\Roaming\.minecraft`
   - Или через TLauncher: настройки → "Папка .minecraft"
2. Скопируйте файл `worldsync-1.21.1-1.0.jar` в папку `mods` внутри `.minecraft`
3. Если папки `mods` нет, создайте её

### 4. Запуск приложения
1. Запустите `minecraft_sync.exe`
2. Введите пароль комнаты Radmin VPN
3. Выберите путь к `.minecraft` (определяется автоматически)
4. Выберите мир из списка
5. Нажмите "Играть"

## Использование

### Создание комнаты (Хост)
1. Первый запустивший приложение становится хостом
2. Введите пароль комнаты и выберите мир
3. Нажмите "Играть"
4. Приложение автоматически:
   - Запустит Minecraft через TLauncher
   - Загрузит выбранный мир
   - Откроет его для LAN-игры
5. Остальные участники могут подключиться

### Подключение к комнате (Клиент)
1. Убедитесь, что хост уже запустил игру
2. Введите тот же пароль комнаты
3. Выберите тот же мир (должен быть у вас локально)
4. Нажмите "Играть"
5. Приложение автоматически подключит вас к серверу хоста

### Статусы в трее
- 🟡 **Жёлтый** - Поиск участников / ожидание
- 🔵 **Синий** - Клиент (подключён к хосту)
- 🟢 **Зелёный** - Хост (игра запущена)
- 🔴 **Красный** - Ошибка / нет сети

## Автоматическая смена хоста

Если хост выходит из игры:
1. Все клиенты фиксируют разрыв соединения
2. Среди оставшихся участников выбирается новый хост с лучшим пингом
3. Новый хост загружает актуальную копию мира
4. Игра продолжается с новым хостом

## Синхронизация мира

### Версионирование
- Каждая версия мира имеет порядковый номер
- Хранится в файле `sync_world_version.txt` в папке мира
- При выходе хоста версия увеличивается

### Периодические бэкапы
- Каждые 5 минут хост создаёт резервную копию мира
- Бэкапы отправляются всем клиентам
- При сбое можно восстановить из последнего бэкапа

### Шифрование
- Все передачи шифруются AES-128-CBC
- Ключ генерируется из пароля комнаты
- Пароль не хранится на диске

## Сборка из исходников

### Сборка приложения
```bash
cd minecraft_sync
pip install -r requirements.txt
pyinstaller --onefile --windowed --name "MinecraftWorldSync" src/main.py
```

### Сборка мода
Для сборки мода требуется:
- JDK 17
- Minecraft Forge MDK 1.21.1
- Gradle

```bash
# В папке с Forge MDK
mkdir mods
cp WorldSyncMod.java src/main/java/com/worldsync/mod/
gradle build
# JAR-файл появится в build/libs/
```

## Решение проблем

### Radmin VPN не найден
- Убедитесь, что Radmin VPN запущен
- Проверьте, что вы подключены к комнате
- IP должен начинаться с `26.`

### TLauncher не запускается
- Проверьте путь к TLauncher в настройках
- Запустите TLauncher вручную перед игрой
- Убедитесь, что профиль Forge 1.21.1 установлен

### Мод не работает
- Проверьте, что мод в папке `mods`
- Убедитесь, что версия Forge совпадает (1.21.1)
- Проверьте логи Minecraft в `logs/latest.log`

### Синхронизация не работает
- Все участники должны использовать одинаковый пароль
- Брандмауэр не должен блокировать порты 45678-45679
- Проверьте логи приложения `minecraft_sync.log`

## Логи

Логи приложения сохраняются в файле `minecraft_sync.log` в папке с программой.

## Безопасность

- Пароль комнаты хранится только в оперативной памяти
- Все сетевые передачи шифруются
- Исходные миры не передаются без шифрования
