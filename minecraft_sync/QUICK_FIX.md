# Быстрое решение проблемы с запуском TLauncher

## Проблема
Программа выдаёт ошибку: `TLauncher not found in standard locations`

## Решение (30 секунд)

1. **Найдите TLauncher.exe на компьютере:**
   - Откройте проводник Windows
   - В поиске введите `TLauncher.exe`
   - Или перейдите по пути: `C:\Users\danil\AppData\Roaming\.tlauncher\`

2. **Скопируйте полный путь:**
   - Кликните правой кнопкой по `TLauncher.exe`
   - Выберите "Копировать как путь" (или скопируйте путь из адресной строки + имя файла)
   - Должно получиться что-то вроде: `C:\Users\danil\AppData\Roaming\.tlauncher\TLauncher.exe`

3. **Создайте файл конфигурации:**
   - В папке с программой синхронизации создайте текстовый файл
   - Назовите его точно: `tlauncher_path.txt`
   - Откройте файл и вставьте скопированный путь
   - Сохраните файл

4. **Перезапустите программу** и нажмите "Играть"

## Альтернативное решение

Если не хотите создавать файл:

1. Запустите TLauncher вручную
2. Выберите версию Forge 1.21.1
3. Дождитесь появления главного меню Minecraft
4. Только после этого нажмите "Играть" в программе синхронизации

Программа автоматически обнаружит запущенный процесс Minecraft.

---

**Примечание:** Сообщения `Listen error: timed out` в логе являются нормальными и означают, что другие участники ещё не подключились. Их можно игнорировать.
